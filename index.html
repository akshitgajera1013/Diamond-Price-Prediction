Valuation Fundamentals

The four pillars the model learns from

Every prediction is built on the same criteria gemologists have used for a century — plus the physical geometry a grading report doesn't always emphasize.

01 · CARAT

Weight

The single strongest price driver — value rises non‑linearly as carat weight increases.

02 · CUT

Craftsmanship

From Fair to Ideal, cut quality determines how brilliantly a stone returns light.

03 · COLOR

D → J Scale

Colorless stones (D) command a premium over warmer, more tinted grades (J).

04 · CLARITY

Inclusions

From IF (Internally Flawless) to I1, clarity measures visible imperfections.
